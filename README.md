# Customer Segmentation – ML Model Deployment 🚀

This project demonstrates end-to-end Machine Learning model deployment using **K-Means clustering** and **Flask**.

## 📌 Project Overview
- Customer segmentation using purchasing behavior
- Trained using K-Means clustering
- Deployed as a web application using Flask

## 🧠 Machine Learning Model
- Algorithm: K-Means
- Features used:
  - Number of Orders
  - Total Quantity
  - Total Spending

## 🛠 Tech Stack
- Python
- Pandas, NumPy
- Scikit-learn
- Flask
- HTML & CSS
